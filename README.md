# Tax Templates

Pre-designed templates for organizing and filing tax documents and returns. Financial institutions and enterprises use these templates to streamline operations and manage fiscal responsibilities, covering W-2s, 1099s, corporate returns, K-1 schedules, and international FATCA/CRS reporting.

## APIs and Resources

### TurboTax / Intuit API
Consumer and business tax preparation via Intuit's platform.
- **Docs:** [https://developer.intuit.com/](https://developer.intuit.com/)

### Xero Tax API
Accounting data integration for tax return preparation.
- **Docs:** [https://developer.xero.com/documentation/xero-app-store/app-partner-guides/tax/](https://developer.xero.com/documentation/xero-app-store/app-partner-guides/tax/)

### QuickBooks Tax API
Financial data for tax document generation from QuickBooks Online.
- **Docs:** [https://developer.intuit.com/app/developer/qbo/docs/develop](https://developer.intuit.com/app/developer/qbo/docs/develop)

### FATCA/CRS Reporting Templates
International account holder reporting for financial institutions.
- **Docs:** [https://www.irs.gov/businesses/corporations/foreign-account-tax-compliance-act-fatca](https://www.irs.gov/businesses/corporations/foreign-account-tax-compliance-act-fatca)
